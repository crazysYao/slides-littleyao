# attention-review

依研究審查教案與簡報的節奏。**只報告，不修改任何檔案**；講師點名哪幾條，再另外動手。

研究依據與可信度：`docs/research/2026-10-20-attention-for-presentations.md`。報告中的「依據」只能引用該文件列出的研究。

## 1. 收集輸入

| 來源 | 必要性 | 用途 |
|---|---|---|
| 有時間軸的教案或大綱(markdown) | 必要 | 節奏類規則 |
| open-slide `slides/<id>/index.tsx` | 選用 | 頁面類規則 |
| Synora deck 產生器或內容檔 | 選用 | 頁面類規則 |

- 每段都要有開始時間或長度。**缺時間軸就停下**，請講師補一份簡易時間表，每段寫：開始時間、長度、類型。不要從頁數推估時間
- 同時確認總時長與時段(上午／下午／全天)，有午餐的話問午餐時間

## 2. 分類每一段，先給講師確認

| 類型 | 算切換 | 關鍵字 |
|---|---|---|
| 講授 | 否 | 預設 |
| 互動 | 是 | 投票、搶答、舉手、提問、QA、Q&A |
| 示範 | 是 | Demo、示範、現場操作 |
| 實作 | 是 | 實作、練習、動手 |
| 討論 | 是 | 討論、兩兩、分組 |
| 休息 | 是 | 休息 |

- 以段落標題判斷類型；內文只用來找段內小練習
- 標題判為講授、但內文出現其他類型關鍵字(例：案例段內文寫「示範三問」)：仍判講授，在備註寫「內文有示範，可能是示範段」，讓講師在確認時改
- 段內含小練習(例：「小練習(4 分)」)：拆成「講授 + 互動」，練習排在段尾，連續講授算到練習開始為止
- 互動再分三種
  - **回顧型**：搶答、回想題、要學員說出前面內容
  - **意見型**：投票、舉手表態
  - **其他**：動手小練習、QA
- 段落帶有 `<!-- attention: 理由 -->` 標註者，標為「豁免」

用表格列出：時間｜長度｜標題｜類型｜(互動的話)回顧型或意見型｜備註。**請講師確認或修正，確認後才進入第 3 步。**

## 3. 節奏類規則

「一節」= 兩次休息之間(或開場／結束到休息)的區間。

| 規則 | 🔴 必改 | 🟡 建議 |
|---|---|---|
| 連續講授(相鄰講授段時間相加，遇到任何切換歸零) | > 20 分 | 15–20 分 |
| 一節內的互動次數(互動、示範、實作、討論都算) | 0 | 1 |
| 第二節起，該節第一段是否為回顧型互動 | — | 不是 |
| 午餐後第一段 | 純講授 | 講授超過一半 |

- 豁免段落不判，但仍計入時間；它前後的講授不連在一起算
- 同一段連續講授只報最嚴重的那一級

## 4. 頁面類規則(有簡報檔才跑)

| 規則 | 🔴 必改 | 🟡 建議 |
|---|---|---|
| 一頁的重點數(條列項、獨立文字卡) | > 5 | 4–5 |
| 投影片上的整段講稿(單一文字區塊) | — | > 60 字 |

- 講稿備註、speaker notes 不算投影片文字

## 5. 引用檢查(教案與簡報都跑)

| 情況 | 等級 |
|---|---|
| 引用 ❌ 迷思：專注力 8 秒／比金魚短、手機在旁就變笨(brain drain) | 🔴 |
| 把 ⚠️ 研究講成定論：「人只能專注 10 分鐘」、「科學證實每 X 分鐘要休息」 | 🟡 |

## 6. 判級原則
- 只有研究文件中 ✅ 的證據能判 🔴；⚠️ 證據最多 🟡；引用迷思例外
- 「做得好」要列：符合研究的設計，例如各節結尾有互動、開頭有回顧型搶答、午餐後排實作
- 建議改法給一到兩個，例如「插一題投票」或「把這段砍短」，不要只給一種

## 7. 輸出格式

```
attention-review：<檔名>(<總時長>，<時段>)

🔴 必改(n)
- <時間或頁碼> <問題>
  依據：<研究，作者 年份>
  建議：<一到兩個改法>

🟡 建議(n)
- ...

🟢 做得好(n)
- ...

⏭️ 已豁免(n)
- <時間> <理由>

📊 節奏總覽
第一節 講授 x%｜互動 x%｜示範 x%｜實作 x%｜討論 x%
第二節 ...
```

- 數量為 0 的等級寫「(0)」並保留標題
- 百分比以分鐘計，四捨五入到整數，加總不必湊成 100%
- 第 5 步引用檢查沒有發現時，在總覽後寫一行「引用檢查：0 條」
- 報告完問講師要處理哪幾條，不要自行修改
