# attention-review skill 設計

> 狀態：已核准並實作(2026-10-20)
> 研究依據：[2026-10-20-attention-for-presentations.md](../../research/2026-10-20-attention-for-presentations.md)

## 目標
依「人類專注心理」研究，審查教案與簡報的節奏，列出問題與改法。

- 階段一(本規格)：審查員
- 階段二(之後另開規格)：規劃顧問，需先釐清與 `create-slide`、`presentation-strategist` 的分工

## 位置
- `.claude/skills/attention-review/SKILL.md`
- 不在 `@open-slide/core` 同步範圍內(`pnpm sync:skills` 只處理同名 skill)

## 輸入
| 來源 | 必要性 | 用途 |
|---|---|---|
| 有時間軸的教案或大綱(markdown) | 必要 | 節奏類規則 |
| open-slide `slides/<id>/index.tsx` | 選用 | 頁面類規則 |
| Synora deck 產生器或內容檔 | 選用 | 頁面類規則 |

- 沒有時間軸：先請講師補簡易時間表(開始時間、長度、類型)，不從頁數猜時間

## 流程
1. 讀教案，把每段分類
2. **列出分類表，請講師確認**，確認後才審查
3. 跑節奏類規則
4. 有簡報檔就跑頁面類規則
5. 輸出報告，**只報告，不自動修改**

## 段落分類
| 類型 | 算切換 | 關鍵字 |
|---|---|---|
| 講授 | 否 | 預設 |
| 互動 | 是 | 投票、搶答、舉手、提問、QA、Q&A |
| 示範 | 是 | Demo、示範、現場操作 |
| 實作 | 是 | 實作、練習、動手 |
| 討論 | 是 | 討論、兩兩、分組 |
| 休息 | 是 | 休息 |

- 段內含小練習：連續講授算到練習開始為止
- 互動分三種：回顧型(搶答、回想題)、意見型(投票)、其他(動手小練習、QA)。「每節開頭回顧」只認回顧型

## 規則與門檻
| 規則 | 🔴 必改 | 🟡 建議 | 證據 |
|---|---|---|---|
| 連續講授 | > 20 分 | 15–20 分 | Bunce 2010、Risko 2012 |
| 一頁重點數 | > 5 | 4–5 | Cowan 2001 |
| 一節互動次數 | 0 | 1 | Szpunar 2013、Freeman 2014 |
| 第二節起開頭回顧 | — | 沒有回顧型互動 | Roediger 2006 |
| 午餐後第一段 | 純講授 | 講授過半 | 午後低谷 |
| 投影片整段講稿 | — | 單一文字區塊 > 60 字 | Mayer 重複原則 |
| 引用 ❌ 迷思 | 有 | — | 研究文件第一節 |
| ⚠️ 研究講成定論 | — | 有 | 研究文件第一節 |

- 只有 ✅ 證據能判 🔴，⚠️ 最多 🟡；迷思例外
- 例外標註：教案內 `<!-- attention: 理由 -->` 標在該段，該段不判，報告列為「已豁免」

## 輸出格式
```
attention-review：<檔名>(<時長>，<時段>)

🔴 必改(n)
- <時間或頁碼> <問題>
  依據：<研究>
  建議：<一到兩個改法>

🟡 建議(n)
🟢 做得好(n)
⏭️ 已豁免(n)

📊 節奏總覽
第一節 講授 x%｜互動 x%｜示範 x%｜實作 x%｜討論 x%
```

## 完成標準
用北科大 [lesson-plan.md](../../ntut-ai-course/lesson-plan.md) 當第一個測試，至少要抓到：
- 🔴 第一節 09:05–09:38 連續講授約 33 分(反轉＋三問＋案例)
- 🔴 第二節 10:17–10:39 連續講授約 22 分(Skill＋MCP/Agent)
- 🟡 第三節開頭是投票(意見型)，不是回顧型
- 🟢 第二節開頭有暖身搶答、各節結尾有互動

另外：
- 加上例外標註後，該段改列為「已豁免」
- 給一份沒有時間軸的大綱，skill 要求補時間表，而不是自己猜

## 不做
- 自動修改教案或簡報
- 從頁數推估時間
- 規劃顧問功能(階段二)
