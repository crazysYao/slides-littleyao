## 為什麼改
2026-11-12 用三個審查角度（學員走查、時間預算、改善方案）檢查現版，結論一致：會失焦。
- 第一節 09:28–09:50 連續 22 分鐘全是設定（Node、OpenCode、AI Studio Key、Vercel 註冊與 `npx vercel login`），學員看不出跟網站的關係
- 第一個成果 10:29 才出現；Vercel 註冊在 09:44，11:23 才用到
- 第一節設定表定 32 分，推估一般 43 分、不順 77 分（推估，未實測）
- Node 一失敗三節全廢；Vercel 登入失敗就沒有網址，兩者都沒有停損
- 講師看過四個修補方案（安裝與訪問並行、進度地圖、09:40 停損、講師代上線），**全部不採用**：它們保留整條工具鏈，只是補洞

## 講師決定的事
- **學員主線一律改用聊天 AI 的網頁預覽**：聊天 AI 訪問 → 基本資料 → 叫它產生網站 → 在同一處跑迴圈改版 → 分享連結
- **學員用 Gemini、ChatGPT、Claude 都可以**（三者都能預覽網頁：Gemini 與 ChatGPT 叫 Canvas，Claude 叫 Artifact）
- **講師用 Claude 示範**整條流程；學員要照著按的步驟（打開預覽、按分享），投影片並列三個工具的截圖，讓學員對照自己的畫面
- **學員下課帶走**：一個公開網址，或可以分享的畫面／連結。Canvas 分享連結即符合
- **基本資料形式不強制**：存成 `.md` 檔或留在對話裡都行，只要學員能把這份 context 交給 Canvas
- **Node、OpenCode、AI Studio Key、Vercel 註冊與登入全部移出學員流程**
- **Agent 只由講師示範**（Claude Code），學員只看
- **Vercel 上架只由講師示範**，約 8 分鐘，當補充；學員課堂上不做
- **空出約 30 分鐘**：平均分給既有實作段，剩下當緩衝，不新增內容（講師標註「暫定」）
- **林小晴網站範本整套拿掉**：`job-site-template` 的 zip、`site/index.html`、`fallback/index.html` 不再出現在學員流程；Canvas 從零做，三個空格決定樣子
- **現在就改簡報**：先照「Canvas 可行」做一版，實測沒過再小改；用量上限、分享鈕失效等備案頁先不做
- **沒有 Google 帳號、或登入後沒有 Canvas 的學員**：改用 ChatGPT 或 Claude，流程相同

## 目標／非目標／反目標
- **目標**
  - 每位學員 11:33 前拿到一個分享連結（或可分享畫面），貼進 Synora 上線牆
  - 學員能說出迴圈四步；知道同一份資料也能拿去寫履歷、準備面試（沿用）
  - 第一個成果（網站 v1）比現版早出現
- **非目標**
  - 學員自己上線 Vercel、自訂網域、GitHub
  - 學員安裝任何軟體
  - 學員操作 Agent
- **反目標**
  - 學員一直在設定環境、不知道在幹嘛（本次改版的起因）
  - 學員只會照貼講師的 Prompt，網站內容不是自己的（沿用）
  - 網站或分享連結上出現私人手機、身分證、住址（分享連結是公開、無密碼的）
  - 有人離開時沒有可分享的連結

## 條件
- 學員約 20 人，剛畢業求職中，多數沒有付費 AI；自帶筆電或只用手機都要能跟
- 助教 1 位；課前聯絡不到學員
- Gemini Canvas 事實（2026-11-12 查 Google 說明頁）
  - 免費，需登入 Google 帳號；未滿 18 歲不能用 Canvas 做網頁
  - 免費版用量「標準額度」，每 5 小時恢復、另有每週上限，確切數字未公布，可能因容量隨時調整
  - 免費版 context 32k token
  - 分享連結是公開連結，任何人拿到都能看，沒有密碼；只能在 `gemini.google.com` 打開，開不進 Gemini App
  - 說明頁把複製／匯出 Canvas 內容寫在「在電腦上」；手機匯出 HTML 不保證可行
  - 第三方回報 iOS 上分享鈕可能變灰

## Prompt 變動
- **訪問卡**：沿用 PR #41 的 5 題版；提示「貼給 Gemini、ChatGPT 或 Claude，等一下同一個對話直接做網站」
- **Prompt ①（追問補「？」）**：改成聊天版，不再寫「寫回檔案」；結尾要 AI 重新輸出完整的「我的基本資料」
- **Prompt ②（網站 v1）**：保留三個空格，改成用 Canvas 產生單一 HTML。參考稿（2026-11-12 給講師試貼的版本）：
  ```
  請用 Canvas（Claude 用 Artifact）幫我做一個個人求職網站，輸出成單一 HTML 檔。

  給誰看：＿＿（例如：面試官、客戶、社團學弟妹）
  風格：＿＿（用三個詞描述，例如：簡潔、溫暖、日系）
  最想讓對方記住的一件事：＿＿

  rule:
  - 只用下面「我的基本資料」裡的內容，沒有的就不要寫，不要編經歷、數字或獎項
  - 資料裡標「？」的地方直接略過，不要補
  - HTML、CSS、JavaScript 全部寫在同一個檔案，不引用外部圖片
  - 手機看也要好看，第一眼就看得出我是誰、想做什麼工作
  - 不要放身分證、住址、私人手機

  我的基本資料：
  （把訪問整理好的那段貼在這裡）
  ```
  - 同一個對話裡做的人，最後一段改成「用上面整理好的我的基本資料」
  - 「風格」空格接第二節找風格選到的風格名稱
- **Prompt ③（讀者審稿）**：骨架不變
- **Prompt ④（Vercel 上線）**：從學員流程拿掉，改為講師示範用
