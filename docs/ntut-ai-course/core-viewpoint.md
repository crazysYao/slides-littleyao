# 講師核心觀點(討論中)

> 狀態：主題、核心句、三節時間表已定稿(2026-10-19)。教案與簡報尚未開始。

## 定稿：核心句(兩層用)
- **主標語**(開場用)：以前缺的是勇氣，現在缺的是好問題。
- **方法層**(課程最後帶走的工具)：三問對應三個能力
  - 為什麼？→ 好奇心
  - 為什麼不用 X？→ 反轉與攻防
  - 有沒有更好的方法？→ 優化思維
- 「為什麼不用 X」與「有沒有更好的方法」都是講師平常會講的口頭禪

## 2026-10-19 討論紀錄

### 怎麼走到這裡
- 先提三個觀點草案，講師選「AI 是很強但沒經驗的新人」最像自己，但仍有落差
- 落差原因：**主題被侷限**。草案都把「講師跟 AI 的關係」當主角，框架太窄
- 改問「不限 AI，最想讓學生改變什麼」，講師回答：**好奇心、優化思維、提問藝術**
- 這三個詞與主題 A 元素相同。A 不夠「是我」的原因推論為主角放錯：A 把它們包成用 AI 的技巧

### 三個能力的關係(講師原意)
- **提問**
  - 從小到大的課堂、到職場，都有人問問題
  - 有的被當好問題，有的被當白癡問題
  - 好問題會拋磚引玉，壞問題讓人覺得沒內容
  - 重點是**判斷什麼是好問題**
- **好奇心**：驅動事情不斷被探索、研究
- **優化思維**：好還要更好，不好的被汰換，好的再更好
- **好奇心 × 優化思維是乘法作用**

### 關鍵觀點：AI 拿掉了「敢不敢問」的門檻
- 過去在那個時空背景下，敢問是優點特質
- AI 時代提問從課堂轉到「你與 AI 之間」，不用是大 E 人、不用怕提問
- 勇氣不再是門檻，差距只剩問題的品質

### 好問題的判準(講師原意)
- **多問一個為什麼**
- **反轉與攻防**：「很明顯可以用 X，那為什麼不用？」

### 核心句草稿
> AI 讓每個人都敢問了，差距只剩會不會問。好問題來自好奇心 × 優化思維：多問一個為什麼，再問一句為什麼不。

- 講師評語：很接近
- 這句是 Claude 壓縮講師的話而成，用字待講師改

## Claude 的提議(講師尚未確認)
- AI 定位為「放大器」：有這三種習慣的人差距被拉更大，但不是課程本體
- 乘法的解讀：只好奇不優化是到處看看；只優化不好奇是原地打磨
- 開場反轉：先讓學生回想「課堂上不敢問」的經驗，再指出這個藉口在 AI 面前已不存在
- 不再 A／B 二選一：以三個能力為骨架，從 A–E 的素材挑代表講師的故事填入

## 情境案例(2026-10-19 定)
- 講師提出的情境原型：**你已經有自己會的做法，AI 給了你不知道的做法，問題就出現了**
- 案例要貼近剛畢業的待業學生，不用講師自己的故事
- 選定場景：**學新技能**
  - 我的做法：找一套線上課，從頭看到尾
  - AI 的做法：先做一個小作品，卡住再查
  - 觸發三問：為什麼要先做？為什麼不先看完課？有沒有更快的學法？
- 已評估未採用：寫履歷、找職缺、準備面試
- 備註：此場景與主題 B「用工程師的腦袋學任何東西」相近，B 的素材可回收

## 課程結構(2026-10-19 定)
- **主題名稱**：為什麼、為什麼不、有沒有更好的：AI 時代的提問力
- **大綱**：思維 → 關鍵字 → 討論與應用
  - 順序理由：先講思維，開場才「是講師」，不像工具課；第二節用三問學關鍵字，等於現場示範「學新技能」
  - 三節都照「好奇 → 反轉攻防 → 優化」的順序走
  - 曾考慮「一節一問」與「關鍵字 → 思維 → 應用」，未採用
- 實作題材：學員各自想學的技能，v1(第一節)→ v3 → 定稿(第三節)
- 技術概念：Prompt / Context / Skill / MCP / Agent 全部保留，集中在第二節
- 學員帶走：三問卡＋自己的學習計畫
