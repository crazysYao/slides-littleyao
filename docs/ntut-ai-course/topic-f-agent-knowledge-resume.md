## 主題與核心
- **主線**：素材 → 動手 → 上線，三節各收一件成品
- **主角不是工具，是講師挑工具、串工具的判斷**；工具會換，判斷帶得走
- **核心句**(Claude 壓縮講師的話，用字待講師改)：工具是租來的，資料是自己的
- **成品**：個人網站；上線是加分題，用 Vercel
- **失敗條件(講師定)**：學員只會照著講師給的 Prompt 做，沒有轉成自己的內容
  - 對策：Prompt 一次比一次給得少，見「Prompt 遞減」

## 工具與講師判斷

| 工具 | 角色 | 選它的理由 | 要不要講給學員 |

| Obsidian | 知識庫 | 本機 .md，任何 AI 都讀得懂，資料主控權在自己手上 | 講(判斷時刻) |
| OpenCode Desktop | 動手的 Agent | 免費、全班一致、帶課快 | **不講**，只強調換成 Claude Code、Codex、Gemini CLI 等任何 Agent 都可以 |
| Vercel | 上線 | 上架快 | 講(判斷時刻) |

- 學員端用 **OpenCode Desktop**(桌面版)，全程不碰終端機、不用裝 Node.js
  - 取捨：學員看不到指令在跑；改成在 Obsidian 裡即時看到筆記被寫入，呈現「Agent 會動手」
- 收尾帶走的「挑工具三標準」(Claude 歸納)：門檻低、不被綁住、成品馬上看得到

### Prompt 原文
**① 完整：Agent 訪問你**
```
請讀這個資料夾裡所有 .md 筆記。你是求職顧問，一次問我一個問題，
幫我補齊缺的細節：我負責什麼、用了什麼工具、有沒有數字成果。
我回答後，把答案寫回對應的筆記。問完 5 題就停。
```

**② 填空：產出網站 v1**
```
讀這個資料夾的所有筆記，做一個給＿＿(誰會看：面試官、客戶、社團學弟妹)看的個人網站，
風格是＿＿，最想讓對方記住的一件事是＿＿。
只能用筆記裡的內容，不要編造經歷。存成 site/index.html，CSS 寫在同一個檔案，手機看也要好看。
```

**③ 骨架：讀者審稿**(投影片一張卡，學員自己補完)
```
你是＿＿(Prompt ② 填的讀者)，打開這個網站看 30 秒。
告訴我：你記住了什麼？想跳過哪裡？還想知道什麼？
我挑一點請你改：＿＿。
```

- **09:03 先按下載，邊聽邊跑(4)**：掃 QR code 下載兩個安裝檔，安裝的同時聽下一段
  - Obsidian：`https://obsidian.md/download`
  - OpenCode Desktop：`https://opencode.ai/download`
  - 🍎 Mac：蘋果選單 →「關於這台 Mac」，Apple M 系列選 Apple Silicon，Intel 選 Intel；.dmg 拖進「應用程式」
  - 🪟 Windows：一般選 x64(ARM 機種才選 ARM64)；跳出藍色警告按「其他資訊」→「仍要執行」
- **09:07 AI 的三個特性(10)**：每個特性接到一個觀念
  - 很強但不認識你 → 知識庫
  - 會動手，不只會聊 → Agent
  - 工具換得很快 → 資料握在自己手上
  - 例子一：同一句「幫我寫自我介紹」，沒給資料得到「積極主動、樂於學習」；給了筆記得到「負責訂位網站前端，上線兩週 120 筆訂位」
  - 例子二：一份知識庫長出個人網站、履歷自傳、面試準備、作品集
- **09:17 判斷時刻：為什麼是 Obsidian(3)**
  - 可用素材：講師網站 Talks 區的 3 小時實作課經驗(例如開南大學 30 人電腦教室)
- **09:20 環境檢查：兩個綠燈(10)**
  - ① Obsidian 建立 vault，例如 `我的知識庫`
  - ② OpenCode Desktop 開啟這個資料夾，打「你好」有回話
  - 同系統兩兩一組，綠燈的人幫隔壁
  - 投影片放常見問題 QR code：下載選錯版本、Windows 警告、找不到資料夾
