## 主題與核心
- **核心概念：問題迴圈**(2026-10-28 改版，設計見 [spec](../superpowers/specs/2026-10-28-ntut-topic-f-problem-loop-design.md))
  - 發現問題 → ① 具體描述 → ② 執行 → ③ 驗證 → ↺ 優化(把落差講得更具體，再跑一輪)
  - 學生隔天要記得的是迴圈；網站是練習迴圈的題材，迴圈也能用在寫履歷、準備面試
  - 三節對應：第一節發現問題、具體描述；第二節執行；第三節驗證與優化
  - 例子：《青之蘆葦》葦人選拔面試(講出來才被看見)、升上 A 隊「言語化的次元不一樣」(講得越細進步越快)
- **主角不是工具，是講師挑工具、串工具的判斷**；工具會換，判斷帶得走
- **成品**：個人網站(本機 `site/index.html`，不上線)
- **失敗條件(講師定)**：學員只會照著講師給的 Prompt 做，沒有轉成自己的內容
  - 對策：Prompt 一次比一次給得少，見「Prompt 遞減」

## 工具與講師判斷

| 工具 | 角色 | 選它的理由 | 要不要講給學員 |
|---|---|---|---|
| Obsidian | 知識庫 | 本機 .md，任何 AI 都讀得懂，資料主控權在自己手上 | 講(判斷時刻) |
| OpenCode Desktop | 動手的 Agent | 免費、全班一致、帶課快 | **不講**，只強調換成 Claude Code、Codex、Gemini CLI 等任何 Agent 都可以 |

- 學員端用 **OpenCode Desktop**(桌面版)，全程不碰終端機、不用裝 Node.js
  - 取捨：學員看不到指令在跑；改成在 Obsidian 裡即時看到筆記被寫入，呈現「Agent 會動手」

## Prompt 遞減

| 時段 | 給多少 | 學員要做的事 |
|---|---|---|
| 10:23 Agent 訪問你 | 完整 Prompt | 照貼，先感受 Agent 會動手 |
| 10:35 產出網站 v1 | 填空 Prompt | 自己決定空格內容 |
| 11:10 讀者審稿 | 只給骨架 | 自己填讀者、挑要改的地方 |
| 11:40 收尾 | 空白 | 寫一則 `我的指令.md` 存進知識庫 |

- **檢查點**：11:25 自己快速看畫面，憑第一直覺挑要改的地方
- **呼應主線**：Prompt 也是自己的資料，存進知識庫，換任何 Agent 都能用

### Prompt 原文
**① 完整：Agent 訪問你**
```
請讀這個資料夾裡所有 .md 筆記。你是求職顧問，一次問我一個問題，
幫我補齊缺的細節：我負責什麼、用了什麼工具、有沒有數字成果。
我回答後，把答案寫回對應的筆記。問完 5 題就停。
```

**② 填空：產出網站 v1**
```
讀這個資料夾的所有筆記，做一個給＿＿(誰會看：面試官、客戶、社團學弟妹)看的個人網站，
風格是＿＿，最想讓對方記住的一件事是＿＿。
只能用筆記裡的內容，不要編造經歷。存成 site/index.html，CSS 寫在同一個檔案，手機看也要好看。
```

**③ 骨架：讀者審稿**(投影片一張卡，學員自己補完)
```
你是＿＿(Prompt ② 填的讀者)，打開這個網站看 30 秒。
告訴我：你記住了什麼？想跳過哪裡？還想知道什麼？
我挑一點請你改：＿＿。
```

## 第一節 09:00–09:50｜發現問題，具體描述
- **09:00 開場：先秀終點(3)**
  - 左邊秀 `https://hi.littleyao.me/zh`：終點的樣子(Next.js 雙語站)
  - 右邊秀講師課前用今天流程重做的單頁版：今天 3 小時做得到的版本
  - 不說左邊是用今天流程做的
- **09:03 先按下載，邊聽邊跑(4)**：掃 QR code 下載兩個安裝檔，安裝的同時聽下一段
  - Obsidian：`https://obsidian.md/download`
  - OpenCode Desktop：`https://opencode.ai/download`
  - 🍎 Mac：蘋果選單 →「關於這台 Mac」，Apple M 系列選 Apple Silicon，Intel 選 Intel；.dmg 拖進「應用程式」
  - 🪟 Windows：一般選 x64(ARM 機種才選 ARM64)；跳出藍色警告按「其他資訊」→「仍要執行」
- **09:07 發現問題(3)**：三頁，指令 → 投票 → 揭曉
  - 講師切到 AI 畫面，只打「幫我寫自我介紹」，不給任何資料
  - 唸出結果，學員在 Synora 投票「這段自我介紹在講你嗎？」(這在講我／不是我)；長條圖一面倒時接「所以這是在座每一個人的自我介紹」
  - 口頭問「問題出在誰？AI 不夠強嗎？」，再揭開：AI 的空泛，是我造成的(它不認識你，因為你什麼都沒說)
  - 備案：現場 AI 或網路出狀況，放事先產生的結果截圖
- **09:10 問題迴圈(7)**：一張迴圈圖
  - 0:00–1:00 回到自我介紹：問題不是 AI 爛，是講得不夠具體 → 發現問題
  - 1:00–3:00 沿圖走一圈，說今天三節各在哪一步
  - 3:00–5:30 青之蘆葦兩個場面：選拔面試(具體描述)、升上 A 隊(優化)
  - 5:30–7:00 網站對照：「不好看」改不動；「標題太小、第一眼看不出我會什麼」AI 改得動；寫履歷、準備面試也一樣
- **09:17 判斷時刻：為什麼是 Obsidian(3)**
  - 可用素材：講師網站 Talks 區的 3 小時實作課經驗(例如開南大學 30 人電腦教室)
- **09:20 環境檢查：兩個綠燈(10)**
  - ① Obsidian 建立 vault，例如 `我的知識庫`
  - ② OpenCode Desktop 開啟這個資料夾，打「你好」有回話
  - 同系統兩兩一組，綠燈的人幫隔壁
  - 投影片放常見問題 QR code：下載選錯版本、Windows 警告、找不到資料夾
  - 時間到不等人：還沒好的人先用網頁版免費 AI，休息時間再補裝
- **09:30 實作：建知識庫(15)**
  - 下載範本 vault：`關於我／學歷／專題／經歷／技能`，每個資料夾一則範例
  - 一件事一則，盡量有數字；投影片放一則好筆記，標出三個要素：做了什麼、我負責哪塊、有什麼數字
  - 更快的方式：舊履歷、作品頁截圖丟給 AI 讀出來，再照三個要素整理成筆記
- **09:45 投票(5)**：「哪一則筆記最像網站素材？」
- 帶走：知識庫 v1

**休息 09:50–10:00**(順便處理沒裝好的人)

## 第二節 10:00–10:55｜執行
- **10:00 暖身搶答(5)**：考迴圈的步驟(空泛時下一步是什麼、驗證要做什麼)
- **10:05 聊天 AI vs Agent(8)**
  - 同一個任務「幫我的專題筆記補上數字成果」並排：聊天 AI 你動手 4 次(複製、貼上、貼回、存檔)，Agent 你動手 1 次(說一句話，它自己讀、改、回報)
  - 差別不在誰比較聰明，而在誰去碰你的檔案
  - 今天示範用 OpenCode，換成任何 Agent 流程都一樣(「Agent 是什麼」頁列出 OpenCode、Claude Code、Codex、Gemini CLI)
- **10:13 講師 Demo：Agent 訪問你(10)**：左邊 OpenCode、右邊 Obsidian 並排，看著筆記變多
- **10:23 實作：讓 Agent 訪問自己(12)**：用 Prompt ①，回答追問，把知識庫補齊
- **10:35 講師 Demo：產出網站(3)**：示範填 Prompt ② 的空格，說明空格怎麼想
- **10:38 找風格(3)**：Synora 連結開 Pinterest 搜「personal website design」，挑 1–2 個喜歡的，用三個詞描述，當作 Prompt ② 的風格空格
  - Agent 不一定看得懂圖，所以要把喜歡的地方翻成文字
- **10:41 文字雲(1)**：「用一個詞告訴我：你想要的網站風格？」
- **10:42 實作：網站 v1(10)**
  - 學員自己填 Prompt ②，用瀏覽器打開看得到就過關
  - 打開方式：Obsidian 對 `site` 資料夾按右鍵，在檔案管理員中顯示 → 雙擊 `index.html`
- **10:52 投票(3)**：v1 滿意度 1–5 分，第三節開場回頭看
- 帶走：補齊的知識庫＋網站 v1

**休息 10:55–11:05**

## 第三節 11:05–12:00｜驗證與優化
- **11:05 判斷時刻：為什麼不讓 AI 一次做完？(5)**：用迴圈回答：一次做完是抽抽樂；先具體描述，再執行、驗證、優化
- **11:10 實作：讀者審稿(15)**：用 Prompt ③ 骨架，讓 Agent 扮演 Prompt ② 填的讀者挑毛病，學員只挑一點叫它改，存成 v2
- **11:25 自己看：第一直覺(8)**
  - 直接看畫面、先不讀內容，憑第一直覺說哪裡最想改，一句話講原因
  - 把這句話丟給 Agent 改，重新整理確認，存成 v3
- **11:33 回到迴圈(7)**：同一張迴圈圖；問台下今天跑了哪幾步、哪一輪改最多；同一個迴圈換到寫履歷、準備面試
- **11:40 收尾(10)**
  - 寫一則 `我的指令.md` 存進知識庫(空白，自己寫)
- **11:50 QA(10)**
- 帶走：網站 v3＋知識庫＋自己的指令＋問題迴圈
