「Skill 的價值，是把一次性的指令，
變成可重複使用的工作方法。」

（約 70 秒）先講一個買飲料的故事：我常去同一家手搖飲，每次都點珍珠奶茶半糖少冰。去久了，店員一看到我就問：「老樣子嗎？」我說對，他就直接做，我不用再講甜度冰塊。這一句「老樣子嗎」，就是 Skill 被啟動了：店員是 Agent，他看到是我，判斷這時候該拿出「老樣子」這本手冊，手冊裡寫著珍奶半糖少冰，他照著做。早上手搖飲那題你點了三次才點對，Skill 就是讓第四次只要說「老樣子」。 珍奶和咖啡都只是例子。在家裡，你可以做一個「每週菜單」Skill，把預算、誰不吃什麼寫進去，每週叫它排一次就好。在辦公室，可以做「Email 整理」Skill，照你的規則分類信件、幫你抓出重點。工程師的世界也一樣，一個後端開發 Skill 可以規定 API 要怎麼寫、程式碼要檢查什麼、測試要怎麼跑。共通點只有一個：你把一次講清楚的做法寫下來，之後 AI 每次都照著做，不用你每次重講。 銜接：所以下次你發現自己對 AI 重複講同一段話，就是該把它寫成 Skill 的時候了。
