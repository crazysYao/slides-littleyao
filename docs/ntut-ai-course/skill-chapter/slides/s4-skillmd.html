# 製作熱拿鐵

## 操作步驟

1. 確認客人需求

2. 準備咖啡與牛奶

3. 萃取 Espresso

4. 加熱牛奶

5. 完成拿鐵

## 注意事項

- 確認材料是否足夠

- 缺少材料時先告知

- 不可假裝已完成工作

① Metadata

名稱與用途：什麼時候該翻這本

② Instructions

操作步驟：一步一步怎麼做

③ Rules

執行規範：哪些事不能做

不是神祕的 AI 模型，
是一份 AI 讀得懂的操作指引。

（約 50 秒）這就是 SKILL.md 的內容，它只是一份 Markdown 文字檔，用記事本就能打開。最上面黃色框叫 Metadata，寫名字和用途，AI 靠這段判斷什麼時候該翻這本手冊，例如客人要拿鐵就用它。中間藍色框是 Instructions，也就是步驟：確認需求、準備材料、萃取、加熱牛奶、完成。最下面綠色框是 Rules，規範哪些事不能做，像材料不夠要先講、不可以假裝做完了。所以 Skill 不是什麼神祕的新模型，就是一份寫給 AI 看的工作說明。 銜接：手冊寫好了，AI 實際接到一句話的時候，是怎麼把它用起來的？
