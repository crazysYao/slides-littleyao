SKILL.md 是核心；其他資料夾只是範例，不是每個 Skill 都需要。

（約 40 秒）一個 Skill 其實就是一個資料夾。這個叫 make-latte 的資料夾裡，最重要的是 SKILL.md，它就是手冊本身，寫著什麼時候用、怎麼做、要注意什麼。旁邊的 recipes 資料夾放補充資料，像熱拿鐵的配方；scripts 放輔助程式，例如檢查訂單有沒有填完整。但請記得，後面這兩個只是舉例，很多 Skill 就只有一個 SKILL.md 而已，一樣能用。 銜接：既然 SKILL.md 是核心，我們直接把它打開來看。
