互動式概念模型

每一次 Prompt，都重新組成一次當下的上下文

技術準確版・非特定模型規格

按「新增 Prompt」逐步查看：模型收到的是當次 Context Window，不是一個永遠完整保存、再固定由下往上讀取的對話檔。

送進模型的實際輸入
3,120 / 4,000 tokens
當次 Context Window每次推理皆為新的運算
系統指令歷史訊息摘要最新 Prompt未送入當次視窗

這一輪可用的材料

全局可用上下文應用程式可選擇提供的資料：對話、檢索結果、工具輸出、文件等。
3 個區塊被納入只有組裝後放得進視窗的 token，才會在這次推理中可見。
起始狀態每一步改變「當次」輸入；模型本身不會在請求間自動保留隱藏記憶。
關鍵校正：畫面由下往上排列是為了閱讀時間線；注意力不是固定由下往上讀取，它也不是一張固定的強度圖。
01 / 組裝

全局可用 ≠ 全部送入

產品或框架會選擇訊息、RAG 檢索片段與工具結果；再受 context window token 上限約束。

02 / 壓縮或截斷

歷史可能被截斷或摘要

較舊內容可能直接移出、改成摘要，或依重要性保留。不同產品與策略結果不同。

03 / 影響

注意力不是固定規則

Transformer 可在已提供 token 間建立關聯；recency bias 常見但不是固定遞減，會受任務、位置、內容與模型影響。
